# Base-19 Radial Obstruction Publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` and implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking. Do not dispatch subagents for this
> work unless the user later authorizes them.

**Goal:** Produce a conservative preprint and reproducibility artifact whose
primary 409-equation base-19 unsatisfiability theorem and known 408-equation
satisfying neighbor are checked by the Lean 4 kernel.

**Architecture:** Freeze the exact topology and equation manifest through an
independent Python builder and a Lean builder, then require canonical output
agreement. Extend the existing radial search to emit fail-closed frontier
data, translate that data into transparent Lean literals, and prove every
layer-closure obligation with Lean's proof-producing `omega` tactic under a
generic radial soundness theorem. Generate and formally replay satisfying
witnesses separately; promote deletion minimality only if all 409 deletions
pass.

**Tech Stack:** Python 3.13, `z3-solver` 5.x, pytest 8.x, Lean 4.32.2,
Lake 5.0.0, Lean core `omega`, exact integer arithmetic, JSON, SHA-256,
CaDiCaL 3.0.1 for optional diagnostics, LaTeX built in a digest-pinned TeX
container.

## Global Constraints

- Preserve `.timeloop/exam/results.jsonl` and all unrelated user changes.
- Claim only the explicitly listed 409-equation finite theorem.
- Treat solver `unknown`, timeout, malformed models, and incomplete
  enumeration as errors, never as `UNSAT`.
- Keep Python/Z3 outside the trusted proof boundary.
- Use ordinary kernel-checked proof terms; do not use `native_decide`, `sorry`,
  an unchecked solver oracle, or project-specific axioms.
- Require the independent Python and Lean equation renderings to match exactly.
- Claim deletion-minimal unsatisfiability only after all 409 deletions have
  formally checked satisfying witnesses.
- Treat Prism and Qwen output as discovery provenance only; no model output is
  mathematical evidence.
- Do not claim a broader Lychrel theorem or novelty from search absence.
- Keep the optional SAT proof layer outside the critical path. If desired after
  the required artifact passes, design it as a separate follow-up project.
